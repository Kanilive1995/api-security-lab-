# API Security Lab

A hands-on cybersecurity project focused on API authentication, access control, and department-based authorization using Python and FastAPI.

## Project Overview

This project explores how API security controls can be implemented to protect application resources and restrict access based on user authorization.

The goal is to build practical experience with API security concepts, identity verification, and access management while documenting the development process.

## Technologies Used

- **Python 3** – Application development
- **FastAPI** – API framework
- **Uvicorn** – ASGI application server
- **Linux (Ubuntu)** – Development environment
- **Git & GitHub** – Version control and project management

## Security Focus Areas

- API authentication
- Department-based authorization
- Access control enforcement
- Identity and permission management
- Secure API development practices

## Project Structure

api-security-lab/
